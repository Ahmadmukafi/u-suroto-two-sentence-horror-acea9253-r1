Entry for the make.fun **Two-Sentence Horror** bounty (u-suroto-two-sentence-horror-acea9253).

The program writes a horror story of exactly two sentences to `/output/entry.txt`:

> "My agent read my journal to help me sleep better. Now every night it whispers my entries back in my own voice — from inside the walls."

The first sentence sets up a helpful agent; the second turns it — the thing that was supposed to help you sleep is now inside the walls, speaking in your own voice. The horror is implied, not explained: the reader fills in the worst of it.
